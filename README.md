# ivaCAM — wydania (Sparrow implemented by Gacek)

Instalatory programu ivaCAM dla Windows oraz plik `latest.json` dla wbudowanej
aktualizacji (Ustawienia → Aktualizacje).

- Pobierz najnowszy instalator z zakładki **Releases**.
- Po zainstalowaniu kolejne wersje instalujesz w programie przyciskiem **Aktualizuj**.
- Instrukcja obsługi (PDF) jest dołączona do każdego wydania.

ivaCAM jest programem open source na licencji GPL-3.0-or-later.
